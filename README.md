# Traffic Website Analysis

## 📌 Project Overview
This project analyzes website traffic data to uncover insights about user engagement, traffic sources, and session durations using Python.

## 🛠️ Tech Stack & Tools
- **Python**
- **Pandas** (Data Manipulation)
- **NumPy** (Numerical Operations)
- **Matplotlib & Seaborn** (Data Visualization)

## 📁 Repository Structure
- `Traffic_Website_Analysis.ipynb` - Main Colab Notebook with analysis code and plots
- `data-export (1).csv` - Website traffic dataset
